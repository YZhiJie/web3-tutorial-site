练习 1：增加 uint64 + uint64 + uint128 结构，比较槽数与 gas

三个字段合计 8 + 8 + 16 = 32 字节，正好占满一个 slot，只需要一次 SSTORE。把下面的结构体和 setter 加进 examples/15-evm-internals/contracts/GasLab.sol：

solidity
struct Packed64 {
    uint64 a;
    uint64 b;
    uint128 c;
}

Packed64 public packed64;

function setPacked64(uint64 a, uint64 b, uint128 c) external {
    packed64 = Packed64(a, b, c);
}

练习 2：用交易收据的 gasUsed 重做对比

estimateGas 是带安全边际的估算，真实成本要读收据的 gasUsed。在 test/GasLab.test.ts 里追加：

it('对比 estimateGas 与交易收据的 gasUsed', async () => {
  const { gasLab } = await loadFixture(deployGasLab)

  const tx = await gasLab.setUnpacked(1, 2, 3)

练习 3：给反汇编器增加函数选择器识别

在 examples/15-evm-internals/src/disasm.mjs 末尾追加。函数分发通常是 PUSH4 <selector> 之后出现 EQ、PUSH2 <dest>、JUMPI，所以按 PUSH4 向后找紧邻的 PUSH2 + JUMPI 即可得到入口 pc：

js
export function findFunctionEntries(bytecode) {
  const instructions = disassemble(bytecode)
  const entries = []

  for (let i = 0; i < instructions.length; i++) {
    if (instructions[i].name !== 'PUSH4') continue

    const selector = instructions[i].pushData
    let destination = null

    for (let j = i + 1; j < Math.min(i + 6, instructions.length); j++) {
      if (instructions[j].name === 'PUSH2' && instructions[j + 1]?.name === 'JUMPI') {
        destination = Number.parseInt(instructions[j].pushData, 16)
        break
      }
    }

    if (destination !== null) {
      entries.push({ selector: `0x${selector}`, destination })
    }
  }

  return entries
}

import { readFileSync } from 'node:fs'
import { id } from 'ethers'
import { findFunctionEntries } from '../src/disasm.mjs'

test('识别函数选择器与入口 pc', () => {
  const artifact = JSON.parse(
    readFileSync('artifacts/contracts/GasLab.sol/GasLab.json', 'utf8')
  )
  const entries = findFunctionEntries(artifact.deployedBytecode)
  const selector = id('setUnpacked(uint256,uint256,uint256)').slice(2, 10)

  assert.ok(entries.length > 0)
  assert.ok(entries.some((entry) => entry.selector === `0x${selector}`))
  for (const entry of entries) {
    assert.ok(Number.isInteger(entry.destination))
  }
})

练习 4：统计部署字节码中的 PUSH0 与 PUSH1 0x00

新建 examples/15-evm-internals/scripts/push-count.mjs（本练习新增，不改现有脚本）：

js
import { readFileSync } from 'node:fs'
import { resolve } from 'node:path'

import { disassemble } from '../src/disasm.mjs'

const artifactPath = resolve(process.cwd(), 'artifacts/contracts/GasLab.sol/GasLab.json')
const artifact = JSON.parse(readFileSync(artifactPath, 'utf8'))
const instructions = disassemble(artifact.bytecode)

const push0 = instructions.filter((instruction) => instruction.name === 'PUSH0').length
const push1Zero = instructions.filter(
  (instruction) => instruction.name === 'PUSH1' && instruction.pushData === '00'
).length

console.log(`PUSH0: ${push0}`)
console.log(`PUSH1 0x00: ${push1Zero}`)

方法要点：

  • 必须用 artifact.bytecode 或 artifact.deployedBytecode，不要拿源码手数字节。
  • 统计前先确认编译器目标 EVM 版本。本仓库没有显式设置 evmVersion，当前 artifact 中 PUSH0 计数为 0；把 hardhat.config.ts 的 solidity.settings 设为 evmVersion: 'shanghai' 后重新编译，才会出现 PUSH0。
  • PUSH1 0x00 要同时判断 name 与 pushData，否则会把 PUSH1 0x01 也算进去。

本仓库当前 artifact 实测是：部署字节码 PUSH0 0 次、PUSH1 0x00 52 次；运行时字节码为 0 次与 49 次。数字会随配置与代码变化，报告时注明测的是哪一份字节码。

练习 5：找出 deployedBytecode 中所有 SSTORE 并解释源码

当前 GasLab 的运行时字节码有 8 个 SSTORE，pc 为：

text
288, 291, 294, 594, 614, 1076, 1114, 1149
1

结合源码可以确认：

  • 288 / 291 / 294 对应 setUnpacked：三个 uint256 各占一个 slot，连续三次写入。
  • 594 / 614 对应 setPacked：两个 uint128 打包在第一个 slot，uint64 写在第二个 slot。
  • 后面的 1076 / 1114 / 1149 位于数组写入路径，必须结合源码映射或运行时 trace 才能逐条归因，不能只凭 pc 猜。

要拿到“这次调用具体写了哪个 slot”，用 Hardhat 的 debug_traceTransaction 过滤 structLogs：

ts
// examples/15-evm-internals/scripts/sstore-trace.ts
import { ethers } from 'hardhat'

async function main() {
  const gasLab = await ethers.deployContract('GasLab')

  const calls = [
    ['setUnpacked', () => gasLab.setUnpacked(1, 2, 3)],
    ['setPacked', () => gasLab.setPacked(1, 2, 3)]
  ] as const

  for (const [name, run] of calls) {
    const tx = await run()
    const trace = await ethers.provider.send('debug_traceTransaction', [
      tx.hash,
      { disableMemory: true }
    ])
    const stores = trace.structLogs.filter((log: any) => log.op === 'SSTORE')
    console.log(
      name,
      stores.map((log: any) => ({
        pc: log.pc,
        key: log.stack[log.stack.length - 1],
        value: log.stack[log.stack.length - 2]
      }))
    )
  }
}

main().catch((error) => {
  console.error(error)
  process.exitCode = 1
})
