练习 1：增加输入框调用 setNumber，并处理非 owner 的 revert

先扩展 ABI。Counter 的 setNumber 只有 owner 能调用，把错误也写进 ABI，便于前端识别：

js
const counterAbi = parseAbi([
  'function number() view returns (uint256)',
  'function increment() returns (uint256)',
  'function setNumber(uint256 newValue)',
  'event NumberChanged(uint256 indexed oldValue, uint256 indexed newValue, address indexed operator)',
  'error NotOwner(address caller)'
])

在 App.vue 中增加状态与函数：

js
import { formatCount, parseCountInput, shortenAddress } from './lib/format.js'

const numberInput = ref('')

async function setNumber() {
  if (!walletClient || !address.value) {
    status.value = '请先连接钱包'
    return
  }

  busy.value = true
  try {
    const newValue = parseCountInput(numberInput.value)
    const hash = await walletClient.writeContract({
      address: counterAddress,
      abi: counterAbi,
      functionName: 'setNumber',
      args: [newValue],
      account: address.value
    })

    status.value = `交易已广播：${shortenAddress(hash)}`
    const receipt = await publicClient.waitForTransactionReceipt({ hash })

    // 交易可能上链但执行失败，必须看收据状态
    if (receipt.status === 'reverted') {
      status.value = '交易执行失败：当前账户不是合约 owner'
      return
    }

    status.value = `已确认，区块 ${receipt.blockNumber}`
    await refreshCounter()
  } catch (error) {
    const detail = error.shortMessage ?? error.message ?? '交易发送失败'
    status.value = detail.includes('NotOwner')
      ? '当前账户不是合约 owner，只有部署者能调用 setNumber'
      : detail
  } finally {
    busy.value = false
  }
}

要点：

  • parseCountInput 会拒绝负数、小数与空值，避免把非法字符串传给 BigInt。
  • 非 owner 调用会以自定义错误 NotOwner revert；钱包里看到的可能是原始错误，前端应翻译成“当前账户无权限”。
  • 交易哈希只代表已广播，最终仍要等收据；失败交易也可能有哈希。
  • setNumber 有权限限制，切换钱包账户后要重新连接，确保 address 与当前账户一致。
练习 2：用 getContractEvents 展示最近 10 条 NumberChanged

把 watchContractEvent 替换为一次性查询。增加状态：

js
const events = ref([])
1

查询函数：

js
async function loadRecentEvents() {
  if (!counterAddress) return

  const logs = await publicClient.getContractEvents({
    address: counterAddress,
    abi: counterAbi,
    eventName: 'NumberChanged',
    fromBlock: 0n,
    toBlock: 'latest'
  })

  events.value = logs.slice(-10).map((log) => ({
    blockNumber: log.blockNumber,
    oldValue: formatCount(log.args.oldValue),
    newValue: formatCount(log.args.newValue),
    operator: shortenAddress(log.args.operator),
    txHash: log.transactionHash
  }))
}

要点：

  • getContractEvents 只覆盖查询区间，不会实时推送；想同时要历史与实时，可以保留监听并另外做一次历史查询。
  • fromBlock: 0n 适合本地链；Sepolia 上应限制区块范围，避免 RPC 超时或限流。
  • log.args 已按 ABI 解码，oldValue / newValue 是 bigint，展示时用 formatCount。
  • blockNumber 可能是 null（例如 pending 日志），本地已确认交易一般不会出现。
练习 3：增加切换网络按钮，并处理用户拒绝

增加函数：

js
async function switchNetwork() {
  if (!window.ethereum) {
    status.value = '未检测到浏览器钱包'
    return
  }

  try {
    await window.ethereum.request({
      method: 'wallet_switchEthereumChain',
      params: [{ chainId: '0x7A69' }] // 31337
    })
    status.value = '已切换到本地 Hardhat 网络'
    await connectWallet()
  } catch (error) {
    // 4902：钱包里还没有这条链
    if (error.code === 4902) {
      try {
        await window.ethereum.request({
          method: 'wallet_addEthereumChain',
          params: [
            {
              chainId: '0x7A69',
              chainName: 'Hardhat Local',
              nativeCurrency: { name: 'Ether', symbol: 'ETH', decimals: 18 },
              rpcUrls: ['http://127.0.0.1:8545']
            }
          ]
        })
        status.value = '已添加并切换到本地网络'
        await connectWallet()
      } catch (addError) {
        status.value = addError.shortMessage ?? addError.message ?? '添加网络失败'
      }
    } else if (error.code === 4001) {
      status.value = '你取消了切换网络'
    } else {
      status.value = error.shortMessage ?? error.message
    }
  }
}

要点：

  • chainId 必须是十六进制字符串。31337 对应 0x7A69，Sepolia 11155111 对应 0xAA36A7。
  • 用户拒绝时钱包通常抛出 code = 4001，不要反复弹窗，给出“已取消”即可。
  • 目标链未添加时抛 4902，可以再请求 wallet_addEthereumChain；添加后仍然可能被用户拒绝。
  • 切换成功后重新连接，让 publicClient / walletClient 绑定到新链，避免继续读旧链数据。
练习 4：为 format.js 增加 formatBlockNumber，并补单元测试

在 examples/06-dapp-vue/src/lib/format.js 末尾增加：

js
export function formatBlockNumber(value) {
  if (value === null || value === undefined) return '—'
  return typeof value === 'bigint' ? value.toString() : String(value)
}
