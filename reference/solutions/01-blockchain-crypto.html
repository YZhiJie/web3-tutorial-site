先确认基线示例可以运行：

bash
pnpm --filter @web3-ex/01-crypto-basics test
1

本页出现的私钥与助记词都是公开测试数据，只能用于本地练习，不要用于任何真实资产。示例代码是教学实现，不应直接用于生产签名或密钥管理。

练习 1：输入只差一个空格时，哈希会怎样变化？

在 examples/01-crypto-basics/test/hash.test.mjs 末尾追加一条断言。哈希具有雪崩效应：输入只改一个字节，输出也会面目全非。

js
test('输入只差一个空格，哈希完全不同', () => {
  const original = keccak('hello')
  const withSpace = keccak('hello ')

  assert.notEqual(original, withSpace)
  assert.equal(
    original,
    '0x1c8aff950685c2ed4bc3174f3472287b56d9517b9c948127319a09a7a36deac8'
  )
  assert.equal(
    withSpace,
    '0x40000f84265ae2330b1336cd8fced7b62dad145130f3469b085aedf6c80f3398'
  )
})

练习 2：消息被篡改后，签名验证为什么应失败？

在 examples/01-crypto-basics/test/keys.test.mjs 顶部补一行 import { verifyMessage } from 'ethers'，然后追加反例。签名本身仍然格式合法，但它绑定的是原始消息的字节；换成另一条消息后，恢复出的地址就不再是签名者。

js
test('篡改消息后恢复出的地址不再匹配', async () => {
  const { signature } = await signAndVerify(privateKey, '欢迎学习 Web3')
  const recovered = verifyMessage('欢迎学习 Web3 ', signature)

  assert.notEqual(recovered, addressFromPrivateKey(privateKey))
})

练习 3：派生 index 3 的地址，并与钱包对照

examples/02-wallet-signing/src/wallet.mjs 已提供 deriveAccount。在示例目录执行：

bash
cd examples/02-wallet-signing
node -e "import('./src/wallet.mjs').then(({ TEST_MNEMONIC, deriveAccount }) => { const account = deriveAccount(TEST_MNEMONIC, 3); console.log(account.path, account.address) })"

这个地址就是 Hardhat 默认账户列表中的第 4 个账户（从 0 开始计数）。在 MetaMask 导入助记词 test test test test test test test test test test test junk 后，界面上通常会把它显示为 Account 4。如果对不上，先检查派生路径是否为 m/44'/60'/0'/0/3。

该助记词全网公开，只能当作一次性测试账户，绝对不要转入真实资产。

练习 4：给 Merkle 树增加第 5 个叶子，奇数叶子还能验证吗？

可以。merkle.mjs 在配对时使用 const right = current[i + 1] ?? left：当叶子数为奇数时，最后一个节点会与自己配对，再参与上一层哈希。

在 examples/01-crypto-basics/test/merkle.test.mjs 末尾追加：

js
test('5 个叶子时每个证明仍然有效', () => {
  const leaves5 = ['tx-1', 'tx-2', 'tx-3', 'tx-4', 'tx-5']
  const root5 = merkleRoot(leaves5)

  assert.equal(root5.length, 66)
  assert.equal(
    root5,
    '0x51d56d440539a089dafbe9bf3ddba06fe5db87ee20cb1dc9ca18a5bb21841ef3'
  )

  for (const [index, leaf] of leaves5.entries()) {
    assert.equal(
      verifyMerkleProof(leaf, merkleProof(leaves5, index), root5, index),
      true
    )
  }

  // 5 个叶子形成 3 层，证明路径长度为 3
  assert.equal(merkleProof(leaves5, 4).length, 3)
})
