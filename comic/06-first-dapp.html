第 06 话 · 第一个 dApp 闭环 ​

对应正文 06 · 第一个 dApp。这一话把前五话拼起来：用 Vue 3 + viem + MetaMask，完成“连接 → 读取 → 写入 → 等确认 → 听事件 → 更新 UI”的最小闭环。所有操作只在测试网。

本章小结 ​

  • dApp 四块：Vue 3 UI、钱包（账户与签名）、RPC 节点、合约（状态与事件）。
  • 连接钱包只共享地址和 chainId，不共享私钥；签名必须用户逐次确认。
  • 网络先校验 chainId，不对就提示切换；入门只碰测试网。
  • 读合约用 publicClient.readContract（eth_call），不签名、不花 Gas，但仍可能 revert。
  • 写合约：simulateContract 预演 → 钱包签名 → sendTransaction → waitForTransactionReceipt。
  • 只有收据 status 成功才更新为“成功”；pending 状态禁用重复提交。
  • 事件用于增量更新；初始化先读当前状态，组件卸载时取消订阅。
  • 错误分类：用户拒绝、余额不足、估算失败、revert、错误网络、RPC 超时；保留原始错误便于排查。
  • 克隆 dApp 靠域名、chainId、合约地址识别；不要输入助记词，不要无限授权。
